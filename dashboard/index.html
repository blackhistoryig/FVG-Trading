How It Works — deterministic math, AI judgment, nothing blurred

Deterministic core

FVG Engine

ATR-based gap filter, MSS + displacement confirmation. Fires the raw directional signal.

→
LLM Agent · Groq

Scout

Contextualizes the FVG signal into a structured thesis + confidence score (openai/gpt-oss-120b).

→
LLM + Rules Agent

Risk Guardian

Hard limits in plain code first (fail-closed), then Groq reasoning. Sets the real stop-loss / hold-time cap, can veto outright.

→
Deterministic script

Executor

Alpaca CLI. Target-aware debit-spread strike selection, multi-leg order placement. No LLM in this step.

→
Deterministic script

Position Monitor

Polls the open position against Risk Guardian's max-loss / max-hold-time and auto-closes when either trips.

Built the Hard Way — 11 real bugs found live, fixed, committed

Silent Misroute Bug
str(Enum) would have flipped every bullish signal into a put spread — caught by schema-diffing before the first live run
Cost-Blind Veto Bug
Risk Guardian set a $50 cap no real spread could satisfy — found only by running against real Groq, fixed in the prompt contract
Zero-Collision Filter
43.7% of backtest trades priced entry & exit off the same bar, faking $0 P&L — skepticism caught it, not luck
Live Chain Quirks
0DTE-only default pages, quotes above spot, strike-window exhaustion — every one hit live, fixed, and committed separately
